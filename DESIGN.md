# Emergency Personal Information Management System
## System and Interface Design

## 1. Application Structure

The application will contain the following main screens:

- Login / Register
- Dashboard
- Personal Profiles
- Add / Edit Profile
- Profile Details
- Emergency Information
- QR Code
- Public Emergency Profile

## 2. Dashboard

The dashboard will provide an overview of the system.

It may display:

- Total Profiles
- Recently Added Profiles
- Quick Profile Search
- Quick Add Profile button

## 3. Personal Profiles

The profiles page will display registered profiles.

Features:

- Search profiles
- View profile
- Add profile
- Edit profile
- Delete profile

## 4. Add / Edit Profile

The form will contain:

### Personal Information
- Name and Surname
- TC Number
- Phone Number
- Email
- Profile Photo

### Emergency Information
- Blood Type
- Allergies
- Emergency Notes
- Emergency Contact
- Preferred Language

## 5. Profile Details

The private profile page will display the complete information of the person.

The user can:

- View information
- Edit information
- Manage emergency information
- Manage privacy settings
- View the profile QR code

## 6. Privacy Settings

The user can select which information will be visible on the public emergency profile.

Example:

- Show Blood Type
- Show Allergies
- Show Emergency Contact
- Show Emergency Notes
- Show Preferred Language

## 7. QR Code

Each profile will have a unique QR code.

Scanning the QR code will open the person's public emergency profile.

## 8. Public Emergency Profile

The emergency profile will be designed primarily for mobile devices.

It will:

- Display only information approved by the profile owner
- Provide important emergency information clearly
- Provide emergency contact information
- Hide private personal information

## 9. Responsive Design

The application will work on:

- Desktop
- Tablet
- Mobile

The QR emergency page will be optimized especially for mobile use.

## 10. Basic User Flow

Dashboard

Create Personal Profile

Add Emergency Information
