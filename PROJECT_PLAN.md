# Personal Information Management System

## Project Purpose

The purpose of this project is to develop a web-based personnel information management system. The application will allow users to manage personnel records through a simple and responsive interface.

## Main Features

- Add new personnel
- List personnel records
- Search personnel
- Edit personnel information
- Delete personnel records
- Validate entered information
- Responsive interface for different screen sizes

## Personnel Information

Each personnel record will contain:

- ID
- Name and Surname
- TC Number
- Phone Number

## Project Type

Full-Stack Web Application

## Planned Technologies

- Frontend: React
- Backend: Node.js and Express
- Database: PostgreSQL
- Version Control: Git and GitHub
- Development Environment: Visual Studio Code
